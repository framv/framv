framv Declarative HTML Office Suite

Video · Docs · Slides · Sheets · Images · Canvas

The Problem

Creating video, documents, slides, and spreadsheets today requires heavy tools — Premiere, PowerPoint, Excel. AI should be able to generate everything from a single HTML file that just works in the browser.

The Solution

framv provides custom HTML elements that render content directly in the browser:

  • <framv-video> — HTML/CSS/SVG → MP4/WebM
  • <framv-docs> — multi-page document → PDF
  • <framv-slides> — presentation → PDF
  • <framv-sheet> — spreadsheet with formulas
  • <framv-image> — HTML → PNG/JPG/WebP
  • <framv-canvas> — infinite canvas

How it works

<framv-video width="800" height="600" fps="30" duration="4" controls>
  <style>
    @keyframes fadeIn {
      from { opacity:0; transform:translateY(20px); }
      to { opacity:1; transform:translateY(0); }
    }
  </style>
  <div style="animation:fadeIn 0.6s ease both">
    <h1>Hello framv</h1>
  </div>
</framv-video>

Why framv

  • ✓ Zero install — works from CDN
  • ✓ AI-native — one HTML file per document
  • ✓ Framework-agnostic — vanilla HTML only
  • ✓ Client-side rendering — browser is the runtime
  • ✓ Headless export — Puppeteer CLI for server use
  • ✓ Open source — MIT license

framv Document

This is a declarative document created with pure HTML. The content is automatically paginated into A4 pages with proper margins.

You can export this document to PDF with a single click, or print it directly from the browser. No build tools, no frameworks — just HTML.

Page 2

Use class="framv-page-break" to force a new page. The document automatically handles page numbering and layout.

  • Multiple page sizes: A4, A3, A5, Letter, Legal
  • Portrait and landscape orientation
  • Customizable margins
  • Built-in PDF export
  • Print-optimized CSS
